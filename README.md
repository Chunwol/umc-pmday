# UMC PM Day 아이디어 디벨롭 조 편성 웹 애플리케이션 (Go + MySQL)

PM Day는 PM들의 아이디어를 직접 확인하고 피드백하며 함께 발전시키는 행사입니다. 이 사이트는 아이디어 디벨롭 활동을 위한 조 편성을 지원합니다.

18개 프로젝트(1조~18조)에 PE 개발자들이 **오픈 시간 카운트다운** 이후 **선착순으로 신청**하고, **누가 먼저 눌렀는지(µs 순번 로그)** 투명하게 확인하며, **전체 PE 참석자 수에 따라 빨리 차는 순서대로 정원을 자동 배분(5명~4명 또는 균등 분배)**하는 통합 Go + MySQL 풀스택 애플리케이션입니다.

## 실행 방법

1. 전용 MySQL 8.0 (포트 3307) 또는 기존 MySQL 실행:
   - 기본 DSN: `root@tcp(127.0.0.1:3307)/umc_pmday?parseTime=true&loc=Local&charset=utf8mb4`
   - 환경변수 `MYSQL_DSN`으로 커스텀 MySQL 연결 가능
   - `PORT` 환경변수로 웹 서버 포트 변경 가능 (기본 `:8080`)
2. 실행 스크립트:
   - `.\scripts\start.ps1` (MySQL 3307 자동 확인/기동 + Go 서버 실행)
   - 또는 `go run ./cmd/server`
3. 접속: `http://localhost:8080`
   - 운영진 비밀번호: `secrets/admin_pin` (`ADMIN_PIN_FILE`) 또는 환경변수 `ADMIN_PIN` (미설정 시 `changeme`)

## PM Day 안내와 참석 취소 신청

- 접속할 때마다 MT 안내가 먼저 표시되고, 닫으면 PM Day 필수 참석 안내가 이어집니다. PM Day는 PM의 아이디어를 확인하고 피드백하는 행사이며, 아이디어 디벨롭 조는 선착순으로 신청합니다. MT 참석·불참 응답은 안내의 구글폼에서 받습니다.
- PM Day 안내 또는 화면 상단에서 참석 취소 신청을 열 수 있습니다. 닉네임·이름·학교·전체 전화번호·취소 사유를 입력하며, 접수 기한은 **2026년 11월 20일 23:59 한국 시간**입니다. 서버에서도 마감을 검사합니다.
- 신청은 운영진 검토용으로 MySQL `attendance_cancellations`에 저장됩니다. 참석 명단과 조 배정을 자동 변경하지 않습니다. 같은 이름·학교·전화번호로 재제출하면 사유가 수정됩니다.
- 운영진 설정에서 인증 후 **취소 신청 목록 조회 / 새로고침**을 누르면 신청자 정보·사유·접수 시각을 확인할 수 있습니다. 이 목록은 공개 현황이나 실시간 스트림에 포함되지 않습니다.
- DB 저장 통합 테스트는 `MYSQL_TEST_DSN`을 설정하고 `go test ./...`로 실행합니다. 연결 계정에 임시 테스트 DB 생성·삭제 권한이 필요하며, 기존 서비스 DB는 사용하지 않습니다.
